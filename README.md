# 📅 Content Calendar - Client Management System

A simple, beautiful content calendar to manage tasks for your clients with login access.

## 🚀 Features

- ✅ User Authentication (Login/Logout)
- 📊 Task Management (Add, Delete, Change Status)
- 🎯 Three Status Categories: Upcoming, Current, Finished
- 📈 Real-time Statistics Dashboard
- 🎨 Beautiful, Responsive Design
- 💾 Data Persistence (LocalStorage)
- 🔔 Toast Notifications
- 📱 Mobile Friendly

## 📦 Installation

### Option 1: Local Testing

1. Download all files to a folder
2. Open `index.html` in your web browser
3. Login with demo credentials
4. Start managing tasks!

### Option 2: GitHub Pages Deployment

1. Create a new GitHub repository
2. Upload all files (index.html, style.css, script.js)
3. Go to Settings → Pages
4. Select branch: `main` or `master`
5. Click Save
6. Access your site at: `https://yourusername.github.io/repository-name`

## 📝 How to Use

### Adding Tasks
1. Login with your credentials
2. Fill in the "Add New Task" form
3. Click "Add Task"

### Managing Tasks
- **Change Status**: Click the status button to cycle through Upcoming → Current → Finished
- **Delete Task**: Click the delete button to remove a task

### Filtering Tasks
- Use filter buttons to view specific task categories
- Click "All Tasks" to see everything
